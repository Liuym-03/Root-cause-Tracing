CKG-QRIT 的 CMAPSS 实验代码

ckg_qrit/cmapss_model.py
    根因定位模型：数据基线、知识图谱先验、因果干预、异常证据、融合、训练与评估。
experiments/compare_cmapss.py
    与 Apriori、知识图谱路径、Noisy-OR、FP-Growth、贝叶斯网络、故障树的对比。
experiments/sensitivity_cmapss.py
    Bagging 规模、规则融合系数和异常权重的敏感性分析。

检查：
    python demo.py

依赖：
    pip install -r requirements.txt
